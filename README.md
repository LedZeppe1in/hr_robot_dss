Установка
------------

### Установка через Composer

Если у вас нет [Composer](http://getcomposer.org/), то вы можете установить его, следуя инструкциям
[getcomposer.org](http://getcomposer.org/doc/00-intro.md#installation-nix).

Затем вы можете установить HR Robot используя следующую команду:

~~~
composer #TODO
~~~

### Установка из архивного файла

Извлеките архивный файл, загруженный с [репозитория HR Robot](https://github.com/LedZeppe1in/hr_robot_dss/archive/master.zip).
